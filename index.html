GT Movies Store

Visit the live site
Django 5.0Python 3.13SQLiteBootstrap 5.3PythonAnywhere

An online movie store. Users browse and search a catalog, read and write reviews, fill a cart, check out, and look back at their order history. Admins manage the catalog and moderate reviews through Django’s admin.

Description

How it’s built

The project is split into four Django apps, each owning one part of the store.

home

The landing page and About page.

movies

The catalog, search, movie detail pages, and reviews — including reporting and moderation.

cart

The session-based cart, checkout, and the Order and Item models.

accounts

Sign up, log in and out, and each user’s order history.

  • The cart lives in the session. It’s a {movie_id: quantity} dictionary, so browsing and adding to a cart never touches the database.
  • Every purchase is saved as an order. Checkout records the order total, plus an Item for each movie with the price and quantity at the moment of purchase.
  • Permissions are enforced on the server. Edit and Delete only appear on your own reviews, and the views check ownership again, so a hand-typed URL can’t edit someone else’s review.

Requirements

Screens & user stories

How each screen and feature responds to the 21 required user stories — what you click, and what happens behind it.

#User storyScreenHow it works
1As a user, I want to see information about the GT Movies Store so I can learn more about the app and its purpose.About

How to do itClick About in the navbar, or in the footer’s Links section. The About page describes the store’s movie library and how its digital platform works, alongside an image.

How it’s builtA dedicated About page served by the home app.

2As a user, I want to register an account so that I can access the GT Movies Store.Sign up

How to do itClick Sign Up in the navbar, choose a username, enter a password twice, and click Sign Up. If something’s wrong, like passwords that don’t match, the error appears as an alert on the form; otherwise you’re sent to the Login page.

How it’s builtA customized UserCreationForm with Bootstrap styling; validation errors render as Bootstrap alerts through a custom ErrorList.

3As a registered user, I want to log in so that I can access my account data.Log in

How to do itClick Login, enter your username and password, and click Login. You land on the home page, and the navbar now shows Orders and Logout with your username. A wrong password shows “The username or password is incorrect.”

How it’s builtDjango’s built-in authentication; the navbar checks whether a user is signed in to decide which links to show.

4As a user, I want to be able to view the list of movies available in the GT Movies Store so I can make my selections.Movies

How to do itClick Movies in the navbar. List of Movies shows a grid of posters, each with a button labeled with the movie’s name.

How it’s builtThe Movies page renders every Movie in the database.

5As a user, I want to search movies per title so I can make my selections.Movies

How to do itOn the Movies page, type part of a title into the Search box and click Search. Only matching movies stay in the grid; searching with an empty box brings them all back.

How it’s builtA case-insensitive title filter passed as the ?search= query parameter.

6As a user, I want to be able to access a shopping cart so I can list all movie items I am willing to purchase.Cart

How to do itClick Cart in the navbar. The Shopping Cart page lists each movie’s ID, name, price, and quantity, with Total to pay underneath.

How it’s builtThe cart is read from the session; a helper in utils.py and a custom get_quantity template filter calculate the quantities and total.

7As a user, I want to be able to add one or more items of a movie to my shopping cart so I can purchase them in the future.Movie detail, Cart, Purchase completed

How to do itOpen a movie, set Quantity (1 to 10), and click Add to cart. You’re taken straight to your cart. When you’re ready, click Purchase to see Purchase Completed with your order number. If you aren’t signed in, you’ll be sent to Login first; your cart is kept, so sign in, go back to Cart, and click Purchase again.

How it’s builtThe cart lives in the session as {movie_id: quantity}. Purchasing requires login, creates an Order plus one Item per movie, and clears the cart.

8As a user, I want to create movie reviews so others can use my insights when searching for movies.Movie detail

How to do itLog in and open any movie. Under Create a review, write in the Comment box and click Add Review. Your review appears in the Reviews list with your username and the date.

How it’s builtA login-required view saves the review against the movie and the current user. The review form only appears when you’re signed in.

9As a user, I want to be able to remove all movie items from my shopping cart so I can have flexibility on what I purchase or not.Cart

How to do itOn the Cart page, click Remove all movies from Cart. The cart empties and the total goes back to $0. The button only appears when the cart has something in it.

How it’s builtResets the session cart to empty.

10As a user, I want to edit my reviews so I have the freedom to change my mind about my reviews.Movie detail, Edit review

How to do itLog in and open a movie you’ve reviewed. Click Edit on your review, change the text on the Edit Review page, and click Edit Review. You’re returned to the movie page with the updated review.

How it’s builtEdit appears only on your own reviews, and the view re-checks ownership before saving.

11As a user, I want to delete my movie reviews so I have the freedom to change my mind about my reviews.Movie detail

How to do itLog in and open a movie you’ve reviewed. Click Delete on your review; it’s removed right away and the page reloads without it.

How it’s builtDelete appears only on your own reviews, and the view only removes a review that belongs to the signed-in user.

12As a user, I want to see the reviews of a movie so I can have information on whether I should purchase a movie or not.Movie detail

How to do itOpen any movie from the Movies page. The Reviews section lists every review with the reviewer’s username, the date, and the comment. No account needed.

How it’s builtThe movie page shows its reviews, leaving out any that have been reported.

13As a user, I want to see the details of a movie so I have the information to make my choices.Movie detail

How to do itOn the Movies page, click the button with a movie’s name. Its page shows the title, Description, Price, and poster, with the quantity picker and reviews below.

How it’s builtEvery movie has its own page at /movies/<id>/.

14As a user, I want to see a list of my orders so I can track what I have purchased and my expenses.Orders

How to do itLog in and click Orders in the navbar. My Orders shows each order’s number, date, and total, with a table of the movies in it. Movie names link back to their pages.

How it’s builtA login-required page listing every order the current user has placed.

15As a user, I want to be able to access the GT Movies Store from any desktop using a web browser, so I can use the app anywhere with an internet connection.Every page

How to do itOpen ellacollins.pythonanywhere.com in any web browser. There’s nothing to download or install.

How it’s builtDeployed to PythonAnywhere.

16As a user, I want the GT Movies Store to feature a responsive Graphical User Interface (GUI) so I can access it through different devices with diverse screen sizes.Every page

How to do itOpen the store on a phone, or make your browser window narrower. The navbar collapses into a menu button, the movie grid goes from four posters per row to three and then one, and the footer hides on small screens.

How it’s builtBootstrap 5.3 grid columns and breakpoints, a collapsing navbar, and fluid images.

17As an administrator, I want to be able to manage (view, create, update, or delete) users from the GT Movies Store so we can keep information up to date.Django admin

How to do itLog in at /admin with an administrator account and open Users to view, add, edit, or delete accounts.

How it’s builtDjango’s built-in authentication admin.

18As an administrator, I want to be able to manage (view, create, update, or delete) movies from the GT Movies Store so we can keep information up to date.Django admin

How to do itIn /admin, open Movies to add a movie with its name, price, description, and poster, or to edit and delete existing ones. The list is sorted by name and has a search bar.

How it’s builtA custom MovieAdmin with name ordering and name search.

19As an administrator, I want to be able to manage (create, update, or delete) reviews from the GT Movies Store so we can keep information up to date.Django admin

How to do itIn /admin, open Reviews to see each review’s movie, author, and whether it’s hidden, then edit or delete it. Unchecking Is hidden restores a reported review.

How it’s builtA custom ReviewAdmin that lists the is_hidden flag.

20As an administrator, I want to be able to manage (create, update, or delete) orders from the GT Movies Store so we can keep information up to date.Django admin

How to do itIn /admin, open Orders, or Items for individual line items, to create, edit, or delete them.

How it’s builtThe Order and Item models are registered in the admin.

21As a user, I want to report inappropriate reviews so that the comment section isn’t cluttered with irrelevant/offensive reviews and the review is removed from the page moving forward.Movie detail

How to do itLog in and open a movie. On a review someone else wrote, click Report. The review disappears from the movie page for everyone.

How it’s builtReport appears only on other people’s reviews. Reporting sets is_hidden, which hides the review while keeping it available to admins.

Process

How I worked

What I built on, what I added, and how I refined it.

  • Following the textbook

    The course directed us to build the store step by step from an assigned Django textbook. The book gave the project its structure: four Django apps, so each part of the store — catalog, cart, accounts, home — could change without disturbing the others.

  • Adding review moderation

    I added a way for users to report reviews. A reported review is hidden from the movie page rather than deleted, so an admin can still see it and decide what to do. That took a new is_hidden field, a report view, a template rule that shows Report only on other people’s reviews, and an admin column for managing hidden reviews.

  • Fixing formatting issues

    Once the features worked, I experimented with the templates’ HTML and CSS to fix formatting issues, adjusting the layout until each page displayed cleanly.

  • Designing for different devices

    People reach the store from phones, tablets, and laptops, so I adapted the HTML and CSS to give each of them a good experience — using Bootstrap’s grid to rearrange content across screen sizes, and a navbar that collapses into a menu on smaller screens.
